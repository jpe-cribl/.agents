# Agent instructions

- Skills live in `skills/<name>/SKILL.md` and use only Agent Skills spec
  frontmatter fields.
- Group skills in `skills.sh.json` and list each plugin in
  `.claude-plugin/marketplace.json`.
- Write and check skills with the agentops `skill-builder` and `skill-eval`
  skills.
- A skill belongs to the organization whose repositories it acts on.
- This repository is public: no hostnames, addresses or private names.
